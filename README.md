# agent-governance

Rules, hooks, skills, and agent definitions for three AI coding tools (Claude Code, Cursor, Codex CLI), each a peer folder here (`claude/`, `cursor/`, `codex/`), synced into its tool's live config directory by `sync.sh`. See `claude/docs/superpowers/specs/2026-09-12-agent-governance-monorepo-design.md` for the design.
