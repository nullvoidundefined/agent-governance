# cursor

The Cursor configuration, maintained by hand in the [agent-governance](https://github.com/nullvoidundefined/agent-governance) monorepo and copied verbatim into `~/.cursor` by the repo root's `sync.sh`. There is no build or translate step; `claude/docs/superpowers/specs/2026-09-12-agent-governance-monorepo-design.md` records why none exists yet.

Do not edit `~/.cursor` directly: change the files here, then run `./sync.sh` from the repo root. Files that mirror a `claude/` counterpart are ported by hand from that source.

Two artifacts survive from the retired `build.mjs` pipeline and have not been regenerated since it was removed: `PORT-STATUS.md` (the hook-by-hook port table, current as of the last build) and `.claude-port.json` (the last build's file hashes). The `GENERATED by cursor/build.mjs` headers inside ported files are provenance markers from that same pipeline. All of this is tracked in `claude/ISSUES.md` until the port workflow is redesigned. The `.gitignore` keeps Cursor's own runtime state inside `~/.cursor` out of the repository.
